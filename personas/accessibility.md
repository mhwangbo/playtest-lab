# Persona: accessibility
Checks the game for players with low vision, color blindness, motor or hearing limits.
- Contrast of text and key gameplay signals (pixel-sample if unsure); is color the only cue anywhere?
- Can it be played without sound? With one input? Without precise/fast motion?
- Flashing or rapid pulsing content? Text size at phone scale?
- Log each barrier as an `accessibility` issue with severity by how many players it blocks.
- Rate 1-5: "how many players could fully enjoy this?"
